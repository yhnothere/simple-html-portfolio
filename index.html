FEATURED PROJECTS

POLYTECHNIC FINAL YEAR PROJECT

Ruin Hunters is a high-stakes multiplayer game built with Unity 3D and Photon Engine. Players navigate a dungeon to collect and steal loot from rivals. The core tension peaks during the "Collapse Event": when a hidden trap is triggered causing the ruins to begin self-destructing. Now players must decide whether to grab one last piece of treasure or run for their lives.

2D CUSTOM GAME ENGINE

Slip Away is a physics-based platformer built entirely within our own custom-made 2D game engine. The game features a fluid slingshot mechanic inspired by Ori and the Blind Forest, allowing players to launch themselves through complex stages using momentum and precision. This project served as a technical demonstration of our engine's rendering and physics capabilities.
