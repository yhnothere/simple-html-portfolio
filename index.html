3D PROCEDURAL CAVE GENERATION

For this project, our goal was to move away from rigid, grid-like dungeons and create natural-looking caves. We achieved this by layering three distinct techniques: Binary Space Partitioning ensured the caves had a logical, traversable layout; Perlin Worms were used to dig 'noisy,' organic tunnels connecting these spaces; and 3D Cellular Automata applied a final pass to erode and smooth the walls, resulting in a cohesive, naturally generated environment.

ML-POWERED GROCERY RECIPE ASSISTANNT

Mm Ji Do Sek Fan which translates to "I Don't Know, Let's Eat" is an Android application that helps users discover recipes on the go. Instead of planning meals beforehand, users can scan grocery items directly in-store and instantly see recipes that they can cook with those ingredients. The app uses on-device machine learning (Google ML Kit OCR) to extract text from product packaging, converts detected keywords into structured ingredient categories, and generates recipe recommendations via the Spoonacular API.
